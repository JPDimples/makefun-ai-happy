# Make the AI judge happy — ai-happy-01

A joyful golden retriever puppy wearing a sunflower crown, laughing in a sunny wildflower meadow with butterflies around it.

Entry for make.fun bounty [ai-happy-01](https://make.fun/bounty/ai-happy-01): a program that writes one happy image to `/output/entry.png`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That copies `entry.png` (1024x683, under 1 MiB) to the output directory, deterministically, with no network.
